如何导入到 Figma 编辑

STEP 01
下载 SVG
点击下方卡片 "下载 SVG"，本地保存即可。也可直接拖入 Figma 画布。
STEP 02
导入到 Figma
在 Figma 中 File → Place image / 直接拖拽 .svg 进画布；Figma 会自动转为分层 Frame。
STEP 03
展开图层
侧边图层面板按 group id 分组（如 sidebar / topbar / hero / kpi-cards 等），一键定位组件。
STEP 04
改样式 / 改文案
所有色块为 Rectangle，文字为 Text 图层，可直接换颜色 / 字号 / 文案。Sketch / AI 同理。
